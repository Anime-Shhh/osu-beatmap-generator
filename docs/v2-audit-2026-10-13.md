The pre-change state was committed and pushed as `f499bd4` on
`architecture-v2-hierarchical-beatgrid`. It includes the previously unpublished
Hermes work. The deployed iLab geometry, trainer, and materializer hashes match
that snapshot. No historical checkpoint or dataset was overwritten. Job 450738
was left queued at the user's request and still uses the old deployment.

## What actually went wrong

1. **The training data was synthetic.** `scripts/materialize_v2_data.py` generated
   six 10-second sine-wave clips, with two made-up difficulty labels each. The
   charts alternate a fixed circle position and a fixed straight slider. The
   script falsely filled provenance with `project-riz/osu-beatmaps`, `ranked`,
   and a real dataset revision. The 12 record identities and six audio hashes
   in iLab's `run_20261010_v2/data/splits.json` match that generator exactly.
   There are four train components, two validation components, and no test
   components. These records cannot teach real music timing, style, curvature,
   or difficulty. The low validation loss is not evidence of human mapping.
2. **The current best checkpoint is planner-only.** At inspection, `best.pt`
   reports stage `planner`, epoch 9, global_step 10, FP32, and gradient
   accumulation 1. That differs from the earlier log ending at epoch 55; the
   checkpoint currently at that path is not the log's claimed best result.
   Its geometry state dictionary is present but was not optimized. The old
   loader treated the presence of that dictionary as evidence it was trained.
3. **Straight sliders were also a data/planner problem.** Curve family and
   anchor count are planner tokens, not decisions made by geometry. The
   synthetic corpus contains only `L` sliders. Native `P`, `B`, and `C` support
   already existed. It is incorrect to say the model merely fell back to `L`
   because geometry was untrained.
4. **Real slider controls were being excluded and distorted.** Four of five
   reference difficulties initially failed preprocessing because some native
   control points lie outside the playfield. A curve control point is not a
   click target. A fifth issue was the eight-anchor vocabulary limit: one
   Normal slider has ten controls. At generation time, clamping controls and
   scaling their polygon to the requested curve length also changes the shape;
   a control polygon's length is not a Bezier or circular arc's length.
5. **Sampling and evaluation had avoidable weaknesses.** Overlapping geometry
   windows were independently sampled and averaged, which blends different
   valid layouts. The CLI never supplied a real difficulty calculator, and
   reranking saturated its distance penalty for badly off-target candidates.
   Validation used condition dropout and changed clock/noise exposure across
   epochs. A new run could overwrite a prior `best.pt` in the same directory.

## Changes implemented

- Replace the synthetic materializer with original-audio/native-chart ingestion
  from local `.osz` archives or the pinned Hugging Face original corpus. Preserve
  actual chart/audio hashes, status and revision; local archives are explicitly
  `unverified-local`, not asserted ranked. Recalculate labels with pinned rosu.
  Construct connected source splits before writing final records, report rejects
  and curve coverage, and checksum every output. Require a fresh output folder.
- Preflight training against the actual split manifest and checksums. Reject
  known falsely labeled sine-wave fixtures. Require an audited corpus with at
  least 20/2/2 train/validation/test components; this is a smoke-test threshold,
  not a claim that such a small corpus produces a good model. Diagnostic runs
  are explicitly marked unsuitable for generation.
- Reject planner-only, zero-step, and diagnostic checkpoints at generation.
  The CLI measures stable/no-mod SR, rejects candidates outside the requested
  tolerance (default 0.5 stars), and rejects onset gaps below the configurable
  10 ms minimum. That minimum is a quality gate, not an SR formula.
- Keep stochastic diffusion, using bounded logit heads plus relative Cartesian
  slider controls. Controls may lie outside the playfield. Expand native
  topology to 32 controls; enforce exactly two controls for `P` sliders and
  reject unsupported source counts instead of silently clipping them.
- Train with denoising loss plus configurable relative spacing, unsigned turn,
  and control-polygon shape losses. Each comparison uses the same corrupted
  reference sample and fades out at high noise. Whole-pattern reflections
  augment training. The defaults are hypotheses for ablation (0.1/0.05/0.1),
  not experimentally proven optimal weights.
- Pack only actual heads/controls into geometry attention. In an all-circle
  window, attention sees one token per object instead of 33 padded slots.
  Sample later windows with the preceding overlap fixed through noisy
  inpainting; do not average independent layouts.
- Expose 16 balanced bar samples per source component per epoch, rather than
  one. Disable validation condition dropout, fix validation RNG/clock exposure,
  preserve early-stopping state on resume, correct partial gradient
  accumulation, reject non-finite loss, and prevent accidental fresh-run
  checkpoint overwrites. Fix access to diffuser configuration through DDP.
- Cache immutable vocabulary family memberships rather than scanning all
  3,297 tokens on every grammar transition. A 100-call local comparison returned
  identical IDs and took 0.097 seconds uncached versus 0.000007 seconds cached.
- Replace byte-by-byte tensor-storage hashing with bulk byte export. A local
  960 KB equivalence check measured 0.588 seconds versus 0.001 seconds with
  identical bytes; this is a microbenchmark, not a full-pipeline speed claim.
- Keep native curve length semantics at export. Remove control-polygon scaling
  from generation. Native path extension is valid; a stricter no-extension
  validation option remains opt-in.

Records are now schema 3 and the vocabulary/geometry representation changed.
Rebuild data and retrain **both** stages. The old synthetic planner is not a
useful pretrained base, and silently reinterpreting old geometry is rejected.

## Why this approach fits the requested behavior

A deterministic audio-to-absolute-XY regression can average mutually valid
layouts. Diffusion's squared noise-prediction loss is different: the noisy map,
noise level, and context identify a denoising problem, and stochastic sampling
models multiple layouts. Replacing diffusion solely because it uses MSE would
remove that benefit. The structural losses add the desired relative pattern
supervision without declaring a rotated/reflected layout wrong.

A universal `distance = constant(SR) * time` rule is also inappropriate. It
would suppress stacked rhythms, spaced streams, jumps, and intentional mapper
variation, and it cannot ensure a particular SR. Learned relative patterns plus
measured realized difficulty are the implemented alternative. Polar coordinates
are not necessary: their angle discontinuity and accumulated boundary drift
need additional handling; relative Cartesian anchors and invariant pattern
losses provide a smaller, testable change.

The complete supplied reference set now materializes: all five maps, with
305 P, 194 B, and 106 L sliders retained. This one-song set is a preprocessing
check, not a training/validation split. Preserve it as a listening/playtest
reference, not a way to tune all training decisions to one map.

The complete V2 suite passed on both macOS and iLab: 93 tests and 28 subtests.
Final targeted regression checks were rerun after the hashing, grammar-cache,
and training-guard changes.
Slurm templates pass shell syntax checks, and `git diff --check` is clean.

The pinned Hugging Face original-corpus smoke test examined five raw tracks and
accepted 15 standard charts from three audio components, rejecting zero eligible
charts. It retained 1,133 P, 313 B, and 677 L sliders across 1,380 bar targets.
The manifest/checksum audit passed and correctly returned `production_ready:
false` (two train components, no validation component, one test component).
The optimized and uncached grammar runs produced identical tensor and metadata
contents for all 15 records; serialized archive bytes need not be identical.
The final smoke corpus is in `codex_v2_20261013/hf-ingestion-smoke-optimized`.

Regression tests cover checkpoint eligibility, non-finite/padded geometry,
relative-pattern invariance and gradients, off-canvas control preservation,
DDP-style wrapping, inpainted overlap, real-file ingestion/checksums, measured
star rejection, curve topology, and balanced bar coverage. Unit tests use
explicit synthetic fixtures and mocked scores only where testing packaging;
they do not claim the mock models generate good maps.

No new full training or GPU job was started. The isolated iLab source directory
is `/common/users/asj102/osu_project/codex_v2_20261013`. Use
`configs/v2_real_preprocess.sbatch` with `SOURCE_DIR` and a new `DATA_DIR`, then
`configs/v2_real_train.sbatch` with those and a fresh `RUN_DIR`. The training
template completes planner training before geometry, using separate checkpoint
directories. Generate only from `RUN_DIR/geometry/best.pt`.

The model still needs a sufficiently varied authentic corpus, full training,
and held-out full-map rollouts/playtests before quality claims. Current geometry
training targets are bar-local (cross-bar coherence is still a limitation).
Current audio features use log-mel and pooled-mel, not pretrained MERT. Training
clocks are oracle clocks; the audio-only clock remains a domain gap. The new
losses and sampler need held-out ablations, including measured SR error,
onset/rhythm distributions, slider-shape distributions, and human playability.
There is no assertion that this code change alone fixes the old map.
